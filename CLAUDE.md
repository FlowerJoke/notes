# notes: Levi's HM study notes as PDF + website

Public repo `FlowerJoke/notes`, published with GitHub Pages at https://flowerjoke.github.io/notes/ (branch `main`, root, `.nojekyll`). Classmates view or download the PDFs there.

## How it works
- `tools/create-pdf` is the only code (Python 3, stdlib). It is symlinked as `~/.local/bin/create-pdf`.
- Source of truth for the notes: the Obsidian vault `~/Levi/Main/Local/Obsidian Vault/Semester 1/<Fach>/Notes/*.md`. **Only the `Notes` folder is exported** (not Übungen, Konzepte, Vorlesungen).
- `create-pdf <Fach>` / `create-pdf all`: converts each note to PDF (pandoc + xelatex, one PDF per note), writes it to `<Fach>/<note>.pdf` in this repo, rebuilds `index.html`, `<Fach>/index.html` and `README.md`, then commits and pushes. Flags: `--no-push` (export and rebuild only), `-o <dir>` (plain export elsewhere, no site, no push, single subject).
- Obsidian handling in `convert()`: `![[x.pdf#page=N&rect=l,b,r,t]]` embeds become cropped images via `pdftoppm` (rect origin is bottom-left, verified); `![[Note]]` embeds are inlined; wikilinks become plain text; `$$\begin{align}..$$` loses the `$$` (LaTeX rejects the nesting); headings directly after a line get a blank line; empty notes are skipped; PDFs of notes that no longer exist are moved to the Trash (`gio trash`).
- Decisions by Levi: slide crops from the lectures are included; the lecture PDFs themselves are NOT published. No disclaimer text on the site. Publishing is automatic (every run pushes).

## Rules for working here
- This repo is public. Never add the lecture PDFs, exercises, solutions, credentials or personal data.
- Use the personal GitHub account `FlowerJoke`, not the work account `FlowerJoke-MI` (`gh auth token --user FlowerJoke` for API calls). Commits use the GitHub noreply email set in this repo's git config; do not change it.
- Never delete files permanently; use `gio trash`.
- `README.md`, `index.html` and `<Fach>/index.html` are generated by `build_site()`. Edit the script, not the output.
- Ask Levi before changing what gets published.

## Needs
`pandoc`, `texlive-xetex` (+ recommended collections), `poppler-utils` (`pdftoppm`, `pdfinfo`) on Fedora.

## Known quirks
- LaTeX writes a timestamp into each PDF, so every run produces a new commit even if the notes are unchanged.
- A note linking to a PDF name that does not exist in the vault shows "not found" in the PDF (currently `02 Variablen` in Einführung in die Programmierung).
